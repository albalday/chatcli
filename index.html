Configuración del Chat

Configura las herramientas agénticas y el contexto temporal que se transmiten al modelo.

🕒 Informar Fecha y Hora al Iniciar Chat

Inserta automáticamente la fecha y hora actual como primer mensaje de la conversación (con respuesta 'OK') para informar al modelo sin invalidar la caché de contexto en las siguientes peticiones.

🔍 Búsqueda en DuckDuckGo en Tiempo Real

Permite al modelo invocar search_web para buscar información actualizada, definiciones, noticias y enlaces web mediante la API de DuckDuckGo.

🌐 Navegación Web y Descarga de Documentos PDF

Permite al modelo invocar fetch_web_page para consultar páginas web públicas y descargar documentos PDF en tiempo real extrayendo su texto al contexto.

⚡ Ejecución de JavaScript Local (Sandbox)

Permite al modelo invocar execute_javascript para calcular, procesar datos o validar algoritmos en un entorno seguro en el navegador.

📊 Visualización de Datos y Gráficos Nativos (SVG)

Permite al modelo invocar render_chart para generar y mostrar gráficos interactivos de barras, líneas o sectores sin librerías externas.

⚡ Caché de Contexto (Context / Prompt Caching)

Reutiliza la memoria caché de contexto (KV Cache / Prompt Caching) en servidores compatibles (OpenAI, Claude, OpenRouter, Gemini, LM Studio, vLLM) reduciendo latencia y costes. Se invalida automáticamente al borrar mensajes del chat.

Toda la configuración se almacena localmente de forma persistente (compatible tanto con file:// como con servidores web).
