Configuración del Chat

Toda la configuración se almacena localmente de forma persistente (compatible tanto con file:// como con servidores web).

Configura las herramientas agénticas y el contexto temporal que se transmiten al modelo.

🕒 Informar Fecha y Hora al Iniciar Chat

Inserta automáticamente la fecha y hora actual como primer mensaje de la conversación (con respuesta 'OK') para informar al modelo sin invalidar la caché de contexto en las siguientes peticiones.

🔍 Búsqueda en DuckDuckGo en Tiempo Real

Permite al modelo invocar search_web para buscar información actualizada, definiciones, noticias y enlaces web mediante la API de DuckDuckGo.

🌐 Navegación Web y Descarga de Documentos PDF

Permite al modelo invocar fetch_web_page para consultar páginas web públicas y descargar documentos PDF en tiempo real extrayendo su texto al contexto.

⚡ Ejecución de JavaScript Local (Sandbox)

Permite al modelo invocar execute_javascript para calcular, procesar datos o validar algoritmos en un entorno seguro en el navegador.

📊 Visualización de Datos y Gráficos Nativos (SVG)

Permite al modelo invocar render_chart para generar y mostrar gráficos interactivos de barras, líneas o sectores sin librerías externas.

⚡ Caché de Contexto (Context / Prompt Caching)

Reutiliza la memoria caché de contexto (KV Cache / Prompt Caching) en servidores compatibles (OpenAI, Claude, OpenRouter, Gemini, LM Studio, vLLM) reduciendo latencia y costes. Se invalida automáticamente al borrar mensajes del chat.

Almacenamiento Local de Conocimiento (RAG)

📂

Para almacenar y consultar tus documentos y ramas de forma local y privada, ZeroChat requiere acceso al directorio zerochat/ en tu carpeta de usuario.

📁 Directorio local: zerochat/
Se gestionará automáticamente la estructura zerochat/RAG/ con tus ramas, resúmenes y documentos indexados.
🌿

Base de Conocimiento (RAG)

🌿 Contexto de Conocimiento Activo

Inyecta resúmenes jerárquicos de la rama seleccionada en el System Prompt y permite al modelo leer capítulos bajo demanda con read_chapter_content.

📦 Tamaño de Contexto por Capítulo (Tokens)

Define la capacidad máxima de tokens por capítulo (16K a 1M tokens) para segmentar documentos y realizar síntesis con el modelo. Protege imágenes y tablas completas.

🌿 ¿Qué es el RAG Agéntico Local?

ZeroChat incorpora un sistema de RAG Jerárquico y Agéntico (Tree-RAG) 100% privado y local. Toda la información se almacena directamente en el sistema de ficheros de tu ordenador (./zerochat/RAG/ en Chrome/Chromium o almacenamiento privado OPFS en Firefox/Safari), sin bases de datos vectoriales pesadas ni dependencias externas.

⚙️ ¿Cómo funciona la indexación y recuperación?
  • Indexación por Capítulos: Al subir archivos (PDF, Markdown o Texto), el sistema los particiona en capítulos protegidos y genera micro-resúmenes densos junto con un resumen global.
  • Contexto Ligero en Prompt: Solo se inyectan en el System Prompt los títulos y micro-resúmenes de la rama activa, ahorrando miles de tokens de contexto.
  • Lectura Agéntica Bajo Demanda: Cuando el usuario realiza una pregunta que requiere datos específicos o citas textuales, el modelo invoca automáticamente la herramienta nativa read_chapter_content(docId, chapterId) para inspeccionar únicamente la sección necesaria.
  • Imágenes y Esquemas sin Sobrecarga: Las imágenes y diagramas técnicos no se incrustan en Base64 pesado dentro de los resúmenes; en su lugar, se indexan sus posiciones en el PDF original y se extraen/transforman a sRGB al vuelo en el momento de visualizarlas en el chat.
🤖 Modelo para Ingesta y Carga de Archivos

Para procesar, particionar y resumir los documentos durante la subida, se utiliza el modelo que esté seleccionado y configurado en ese momento en el chat.

💡 Recomendación de modelo local: Se recomienda encarecidamente utilizar un modelo local rápido y ligero. Las pruebas de desarrollo y validación se han realizado satisfactoriamente con LM Studio y el modelo Gemma 4 A4B (con una ventana de contexto de 128K).
📁 Ubicación de Archivos, Exportación e Importación
  • Ubicación de Archivos: En Chrome/Chromium se guardan en la carpeta local ./zerochat/RAG/ (con un fichero rama.md por rama y subdirectorios 0001/, 0002/ que paginan cada 100 archivos). En Firefox/Safari se guardan en el sistema privado OPFS.
  • Exportar Rama Completa: En la pestaña Gestión de Ramas y Documentos, selecciona la rama deseada y haz clic en 📤 Exportar para descargar un paquete comprimido .rag.gz conteniendo la estructura completa del directorio (documentos originales, resúmenes, capítulos e índices).
  • Importar Rama: Haz clic en 📥 Importar y selecciona un paquete .rag.gz (o un archivo JSON legado) para restaurar la rama de conocimiento completa inmediatamente con todos sus archivos y configuraciones.
