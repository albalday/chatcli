Configuración del Chat

Configura las herramientas agénticas y el contexto temporal que se transmiten al modelo.

🔍 Búsqueda en Internet en Tiempo Real

Permite al modelo invocar search_web para buscar información actualizada, noticias, enlaces y artículos en internet mediante APIs abiertas sin bloqueos.

⚡ Ejecución de JavaScript Local (Sandbox)

Permite al modelo invocar execute_javascript para calcular, procesar datos o validar algoritmos en un entorno seguro en el navegador.

🌐 Consulta de Páginas Web en Tiempo Real

Permite al modelo invocar fetch_web_page para consultar URLs y páginas web públicas en tiempo real a través del navegador.

🕒 Enviar siempre Fecha y Hora Actual

Inyecta automáticamente la fecha y hora local del sistema en el contexto del prompt para que el modelo esté siempre orientado temporalmente.

Toda la configuración se almacena localmente de forma persistente (compatible tanto con file:// como con servidores web).
